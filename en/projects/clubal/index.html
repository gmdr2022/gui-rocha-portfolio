ClubAL

The Operador module is moving to the web without abandoning ClubAL’s local-first foundation.

Operação, Rotinas and Consulta remain in the Windows base. The Operador module is moving to a web platform under validation, with the Flet weather feature integrated.

  • Local-first Windows application
  • Operação · Rotinas · Consulta
  • Web platform under validation
  • Weather/Flet integrated

Operational information gets lost when every environment improvises.

Spreadsheets, paper and scattered messages create different versions of the same routine. ClubAL centralizes records on the responsible PC and separates editing from reading.

  • One source of record
  • Visibility by environment
  • Local operation

Each module handles one part of the work.

The product separates responsibilities across three modules: Operação records and publishes; Rotinas displays only approved information; Consulta provides authorized reading without opening editing.

  • Operação · edit and publish
  • Rotinas · display approved information
  • Consulta · read without editing

The Operador module is moving to the web platform.

Operação, Rotinas and Consulta remain in the Windows base. The web platform is being validated with synthetic data and integrates the Flet weather feature.

  • Windows · current base
  • Web platform · under validation
  • Weather/Flet · integrated
