Local First Checklist

Muestro una arquitectura local-first en un ejemplo compacto.

Publiqué una aplicación Python de código abierto con checklist en JSON local, línea de comandos, pruebas y CI.

  • Python CLI
  • JSON local
  • Pruebas + CI

Lo bastante pequeño para entenderlo por completo.

Mantuve las tareas en un archivo JSON local y dejé las operaciones sencillas disponibles desde la línea de comandos.

  • Sin servicio remoto
  • Persistencia legible
  • Documentación directa

La simplicidad también necesita pruebas.

Protejo las operaciones principales con pruebas unitarias, compilación Python y un smoke test sin añadir infraestructura a la aplicación.

  • Pruebas unitarias
  • CLI verificable
  • Workflow de validación

Versión 1.0.0 publicada.

Publiqué estructura, documentación, pruebas y una elección arquitectónica coherente en un alcance reducido.

  • Código público
  • Release versionada
  • Sin dependencia de nube
