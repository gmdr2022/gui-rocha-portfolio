ClubAL

Rutinas e información operativa organizadas para quienes registran, publican y consultan.

ClubAL reúne rutinas, consultas e información operativa en módulos conectados. La base actual para Windows sigue disponible mientras el nuevo Operador Web avanza en desarrollo y validación.

  • Aplicación para Windows
  • Operación, rutinas y consulta
  • Nueva versión web en validación
  • Pronóstico del tiempo integrado
Rol
Dirección de producto y desarrollo de la base local-first, incluida la separación de responsabilidades y la evolución de Operador hacia la web.
Situación operativa
Hojas de cálculo, papeles y mensajes independientes producen versiones contradictorias. ClubAL centraliza el registro en el ordenador responsable y separa edición, publicación y consulta.
Contribución
Estructuré el producto para separar a quienes registran y publican de quienes solo consultan. Esta división reduce ediciones indebidas y mantiene una fuente local de información aprobada.
Evidencia y resultado
Capturas con datos demostrativos documentan Operação, Rotinas, Consulta y el pronóstico del tiempo integrado en los módulos actuales para Windows.
Estado
