Local First Checklist

Eu mostro uma arquitetura local-first em um exemplo compacto.

Eu publiquei uma aplicação Python de código aberto com checklist em JSON local, linha de comando, testes e CI.

  • Python CLI
  • JSON local
  • Testes + CI

Pequeno o suficiente para entender por inteiro.

Eu mantive as tarefas em um arquivo JSON local e disponibilizei as operações simples pela linha de comando.

  • Sem serviço remoto
  • Persistência legível
  • Documentação direta

Simplicidade também precisa de prova.

Eu protejo as operações principais com testes unitários, compilação Python e smoke test, sem adicionar infraestrutura ao aplicativo.

  • Testes unitários
  • CLI verificável
  • Workflow de validação

Versão 1.0.0 publicada.

Eu publiquei estrutura, documentação, testes e uma escolha arquitetural coerente em escopo reduzido.

  • Código público
  • Release versionada
  • Sem dependência de nuvem
