04 · Fila local para validações humanas

Produto local · Windows

Codex Checkpoint

O agente registra. A pessoa valida quando puder. O contexto permanece.

Fila local que preserva testes pendentes, decisões e feedback entre sessões de trabalho assistidas por agentes.

  • WPF / .NET
  • Sem conta
  • Fila durável

Nem todo teste pode ser resolvido durante a sessão.

Gameplay, avaliação visual, dispositivo, autenticação e decisões práticas dependem de uma pessoa ou de outro ambiente. Sem uma fila, esse contexto desaparece.

  • Pendências entre sessões
  • Vários projetos
  • Histórico de feedback

Uma fila de validação — não outro chat.

O agente registra o checkpoint; Gui volta quando puder e deixa uma decisão ou feedback acionável.

  • Chaves sem duplicatas
  • Status e notas
  • Importação de cartões validada

Aplicação nativa e instalável.

Interface, linha de comando e integração por arquivos formam o produto. Os builds atuais ainda não têm assinatura de código, e isso permanece declarado.

  • Dados locais
  • Backup e recuperação
  • Builds não assinados
