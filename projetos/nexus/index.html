05 · Central Windows para projetos locais

Ferramenta local · Windows

NEXUS

Projetos diferentes, um ponto de entrada.

Central Windows para abrir projetos, recursos e verificações a partir de um catálogo local.

  • C# WPF
  • Catálogo JSON
  • Sem nuvem

Projetos locais acumulam atalhos, scripts e instruções dispersas.

Quando cada produto tem seu próprio runtime, encontrar a ação certa vira trabalho antes do trabalho.

  • Múltiplos repositórios
  • Ferramentas diferentes
  • Validações esquecidas

Uma mesa de comando gerida por catálogo.

Cada cartão apresenta ações, referências e verificações sem misturar os runtimes dos produtos.

  • Catálogo JSON
  • Ações por projeto
  • Alvos ausentes ficam desabilitados

Ferramenta de desenvolvimento local.

Build, self-test e render são reproduzíveis. NEXUS organiza o trabalho no computador; não é um runtime embutido nos produtos.

  • Inicialização offline
  • Validação em segundo plano
  • Sem publicação automática
